# Калькулятор вкладов

Расчёт банковского вклада: проценты, капитализация, пополнения и частичные
снятия, налог на доход, график по месяцам и эффективная годовая ставка.

Две версии:

* **Консольная программа и Python-библиотека** — описаны ниже, нужен только
  Python 3.10 или новее, зависимостей нет.
* **Приложение для Android** — готовый файл `deposit-calc.apk` в корне
  репозитория (31 КБ, Android 8.0+); исходники и инструкция по установке —
  в [`android/`](android/README.md). Расчётное ядро портировано на Java,
  результаты обеих версий совпадают до копейки.

## Быстрый старт

```bash
python -m deposit_calc -a 500000 -r 16 --term 12 --cap ежемесячно --schedule
```

Без аргументов программа запускает диалоговый режим — она сама спросит сумму,
ставку, срок и остальное:

```bash
python -m deposit_calc          # то же самое, что и python -m deposit_calc -i
```

## Возможности

* **Капитализация** — нет, ежедневная, ежемесячная, ежеквартальная,
  раз в полгода, ежегодная.
* **Пополнения** — регулярные (`--topup`) и разовые (`--flow`).
* **Частичные снятия** — та же опция `--flow` с минусом, с контролем
  неснижаемого остатка (`--min-balance`).
* **Налог на процентный доход** — ставка (`--tax-rate`) и необлагаемая
  сумма (`--tax-free`). Для российского НДФЛ вычет равен
  1 000 000 ₽ × ключевая ставка; при ставке 16 % это 160 000 ₽.
* **График по месяцам** (`--schedule`) — остатки, начисления, капитализация.
* **Сравнение схем капитализации** (`--compare`) на одних и тех же условиях.
* **Выгрузка в JSON** (`--json`) для дальнейшей обработки.

## Примеры

```bash
# вклад с ежемесячным пополнением на 10 000 ₽, срок 540 дней
python -m deposit_calc -a 100000 -r 14 --term 540д --topup 10000

# три года под 18 % с учётом НДФЛ и вычета 160 000 ₽
python -m deposit_calc -a 1000000 -r 18 --term 3г --tax-rate 13 --tax-free 160000

# разовое пополнение и частичное снятие
python -m deposit_calc -a 300000 -r 15 --term 12 \
    --flow 01.03.2026:50000 --flow 01.06.2026:-20000

# какая схема капитализации выгоднее
python -m deposit_calc -a 200000 -r 17 --term 24 --compare

# машиночитаемый результат
python -m deposit_calc -a 200000 -r 17 --term 24 --cap ежемесячно --json
```

## Аргументы командной строки

| Аргумент | Назначение |
| --- | --- |
| `-a, --amount` | сумма первоначального взноса |
| `-r, --rate` | ставка, % годовых |
| `--start` | дата открытия (`ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД` или `сегодня`); по умолчанию сегодня |
| `--term` | срок: `12` (месяцев), `18м`, `540д`, `3г` |
| `--end` | дата закрытия — альтернатива `--term` |
| `-c, --cap` | капитализация: `нет`, `ежедневно`, `ежемесячно`, `ежеквартально`, `полгода`, `ежегодно` |
| `--topup` | сумма регулярного пополнения |
| `--topup-period` | периодичность пополнений в месяцах (по умолчанию 1) |
| `--topup-day` | число месяца для пополнений |
| `--flow ДАТА:СУММА` | разовая операция: «+» — пополнение, «−» — снятие; можно повторять |
| `--min-balance` | неснижаемый остаток |
| `--tax-rate` | ставка налога на процентный доход, % |
| `--tax-free` | необлагаемая сумма дохода |
| `--currency` | обозначение валюты (по умолчанию `₽`) |
| `-s, --schedule` | напечатать график по месяцам |
| `--compare` | сравнить все схемы капитализации |
| `--json` | вывести результат в JSON |
| `-i, --interactive` | диалоговый режим |

## Как считаются проценты

Проценты начисляются **ежедневно на текущий остаток**:

```
процент за день = остаток × ставка / 100 / дней_в_году
```

`дней_в_году` — 365 или 366 в зависимости от того, високосный ли год, которому
принадлежит день начисления (обычная практика российских банков). Начисление
идёт за каждый день периода `[дата открытия, дата закрытия)`, то есть ровно
столько дней, сколько длится вклад.

В дату капитализации накопленные проценты округляются до копеек и
присоединяются к остатку — дальше проценты начисляются уже на увеличенную
сумму. Если капитализации нет, проценты копятся отдельно и выплачиваются
в конце срока, не увеличивая базу начисления.

**Эффективная ставка** считается как внутренняя норма доходности (XIRR) по
всему денежному потоку вкладчика — с учётом дат пополнений, снятий и налога,
поэтому она корректна и для вкладов с пополнением.

Все суммы хранятся в `Decimal`, округление до копеек — «половина вверх»
(как в банковском учёте), поэтому копеечных расхождений с накоплением нет.

## Использование как библиотеки

```python
from datetime import date
from decimal import Decimal

from deposit_calc import Capitalization, DepositParams, calculate, periodic_cash_flows

params = DepositParams(
    amount=Decimal("500000"),
    annual_rate=Decimal("16"),
    start=date(2026, 1, 1),
    end=date(2027, 1, 1),
    capitalization=Capitalization.MONTHLY,
    cash_flows=periodic_cash_flows(date(2026, 1, 1), date(2027, 1, 1), Decimal("10000")),
    tax_rate=Decimal("13"),
    tax_free_income=Decimal("160000"),
)

result = calculate(params)
print(result.payout)          # сумма к выдаче
print(result.total_interest)  # начислено процентов
print(result.effective_rate)  # эффективная ставка, % годовых

for row in result.rows:       # график по месяцам
    print(row.start, row.closing)
```

## Ограничения

* Ставка постоянна на всём сроке — лестничные и плавающие ставки не поддерживаются.
* Досрочное закрытие с пересчётом по ставке «до востребования» не моделируется:
  чтобы увидеть результат на промежуточную дату, укажите её в `--end`.
* Налог рассчитывается на всю сумму процентов за срок вклада и удерживается
  в конце; разбивка по налоговым периодам не делается.
